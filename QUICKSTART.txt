================================================================================
3 EXPERIMENTAL VARIANTS
================================================================================

V1: LSTM ONLY (Baseline)
   • Student LSTM learns independently via policy gradient
   • No Teacher, no LLM
   • Fastest but least performant

V2: LSTM + TEACHER (No LLM)
   • Student learns from Teacher LSTM via distillation
   • Teacher observes full state, Student only partial
   • Moderate speed, better performance

V3: FULL SYSTEM (LSTM + LLM Guidance)
   • Teacher uses Ollama Gemma3 for strategy guidance
   • Student learns from Teacher+LLM
   • Best performance, slower inference

KEY CONCEPTS
================================================================================

POMDP (Partially Observable Markov Decision Process):
  • Student sees: Only robot positions (8-dim)
  • Teacher sees: Positions + velocities (17-dim)
  • Goal: Student learns to perform well with limited observations

KNOWLEDGE DISTILLATION:
  • Teacher: Expert policy (trained first)
  • Student: Learns to mimic Teacher
  • Loss: KL divergence (action distributions) + MSE (hidden states)

LLM GUIDANCE:
  • Uses Ollama (local LLM server) with Gemma3
  • Generates strategy embeddings from current state
  • Helps Teacher make better decisions

================================================================================
TROUBLESHOOTING
================================================================================

Q: "ModuleNotFoundError: gymnasium"
A: pip install gymnasium[mujoco]

Q: "Ollama connection failed"
A: 
  - Check Ollama is running: ollama serve
  - Use Docker: docker run -d -p 11434:11434 ollama/ollama
  - Skip V3: python ablation_pipeline.py --variants V1 V2

Q: "Out of memory"
A: Reduce in config.py:
  BATCH_SIZE = 8           # Instead of 16
  LSTM_HIDDEN_SIZE = 64    # Instead of 128

Q: "Too slow on CPU"
A: Use GPU (set in config.py):
  DEVICE = "cuda"  # Default
  # Or reduce episodes:
  NUM_EPISODES = 20
